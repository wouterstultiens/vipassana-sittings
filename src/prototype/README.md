# PROTOTYPE: week grid, filters, detail panel

Throwaway code. Answers "how should the calendar look and behave?" for
[Prototype: the week grid, filters, and detail panel](https://github.com/wouterstultiens/vipassana-sittings/issues/10).

Three variants on `/`, switchable with `?variant=A|B|C` or the floating bar
(arrow keys work too). Run with `corepack pnpm dev` after cloning the private
data repo into `data/`.
